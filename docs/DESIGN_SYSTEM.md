# Exam — Light Design System

## Direction
Calm gamification: premium enough for adults, friendly enough for younger students.

## Tokens
- Background #F7F9FC
- Surface #FFFFFF
- Text #0F172A / secondary #64748B
- Primary #3B6CF6
- Indigo #5C5CF6
- Mint #2CCB8C
- Amber #F5A524
- Coral #F26D6D
- Purple #8B5CF6
- Border #E6EAF2

## Shape
- Horizontal padding 20
- Small card radius 16
- Core card radius 20
- Hero/paywall radius 24
- Primary CTA height 56

## UX rules
1. One dominant CTA per screen.
2. Never expose the whole toolset on Home.
3. AI is contextual: prefer task language over "AI Generate".
4. Wrong answers should feel corrective, not punitive.
5. Wrap default platform controls in Exam components.
6. Motion is short, springy and purposeful.
