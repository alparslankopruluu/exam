# exam

Native iOS + Android exam-preparation app.

## Product direction
- Light, calm, premium study UI
- Exam-first onboarding
- Personalized daily study plan
- Adaptive practice and mistake review
- AI tutor, scan-to-solve, notes-to-quiz
- Focus/Pomodoro sessions
- Subscription + optional credits for expensive AI media generation

## Apps
- `ios/` — SwiftUI
- `android/` — Jetpack Compose

## Design language
- Warm off-white backgrounds
- Soft blue/indigo primary accent
- Pastel subject accents
- 20–24pt card radii
- Large custom CTAs
- Minimal shadows
- No default-looking platform controls

The first implementation slice covers the shared design tokens, onboarding shell, and Today dashboard.
